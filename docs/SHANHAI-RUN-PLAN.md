# 山海逃亡 · 实施与验收范围

目标：以《山海经》的异兽、山川和传说为故事背景，制作具有《神庙逃亡》核心操作与追逐节奏的完整 3D 跑酷小游戏。独立目录 `games/shanhai-run`，Cocos Creator 3.8.8 + TypeScript，pnpm 工作区，提供 Web / 微信 / 抖音目标并进入合集大厅。

## 玩法与内容

- 第三人称向前自动奔跑。真实的直角路口、提前预告、转弯时机窗和转向镜头；错过路口会坠落。普通路段左右移动收集，路口左右输入用于转弯。上滑跳跃、下滑滑铲；桌面方向键 / WASD、空格跳跃，并有可选触摸辅助按键。
- 断桥、盘根、低梁、落石、火障、移动障碍。跳跃、滑铲和横移各有用途，生成器保证可反应的间隔与可通过路线，不能用随机叠加制造无解地形。
- 守山兽追逐：绊倒后迫近，连续失误被捕；跳跃、滑铲、受击、坠落、转弯和死亡都有可读动画与音效。
- 昆仑悬道、青丘古林、赤水丹崖、归墟海桥四种场景，区分路面、植被、地标、远景、色彩和障碍节奏。无尽模式持续生成、逐渐提速并轮换区域；八项有限试炼；固定日期种子的每日挑战；可重复的操作教学。
- 收集灵玉，使用引玉铃、玄龟符、乘风翎等跑酷法宝；角色装扮与法宝升级、签到、任务、成就、本地最高纪录和图鉴。跑酷成长独立存档，不依赖网页大厅，不伪装在线排行榜。
- 跑酷主线：带走照夜玉后惊醒守山兽，沿失落古道寻找散落山海图。角色、场景、图鉴文案和几何美术原创，游戏机制参照《神庙逃亡》。

## 视觉方案

- 配色：云青 `#bddbd5`、山黛 `#467e76`、墨绿 `#183e39`、旧石 `#d7c7a2`、朱砂 `#bc604d`、鎏金 `#e3b55f`。主画面以青绿山水与金色拾取路线建立辨识度；赤水、青丘和海桥使用独立环境调色。
- 字体：标题用系统中文衬线（Noto Serif CJK SC / 宋体风格），操作与数字用系统中文无衬线。手机标题约 44–54px、正文 14–16px、辅助 12px；明确对比和至少 44px 的主要触摸区域。
- 构图：游戏世界占据全屏，人物位于下方三分之一，跑道通向山门与云海。主菜单在真实场景上呈现竖排感中文标题与单一「开始逃亡」主按钮。战斗仅保留距离、灵玉、追逐状态与暂停；成长和试炼放在独立浮层。

```text
手机                         桌面
┌ 山海逃亡      灵玉 ┐       ┌远山── 距离 / 灵玉 ───────── 暂停┐
│   山门 / 远山       │       │      山门与连续栈道             │
│      曲折古道       │       │              跑道              │
│      拾玉路线       │       │              行者              │
│       行者          │       │  路口提示              操作说明 │
│  开始逃亡 / 辅助键  │       └───────────────────────────────┘
└试炼  行装  山海录──┘
```

方案自查：辨识度来自实际山川、兽面山门、飞檐、衣带与追兽，不依赖通用卡片仪表盘。主菜单避免把任务和商店堆在跑道上；关卡区别必须体现在几何和玩法，不能只改背景色。先实现可运行的操作闭环并截图，再按参考视角迭代美术；极简版不是最终交付。

## 验收清单

1. 检查官方参考资料并记录来源、时间与可观测机制；能访问的网页版采集实际截图。参考素材只用于研究，不作为发布素材。
2. 纯规则测试覆盖转弯窗口、连续横移、跳跃/滑铲碰撞、追逐、道具、死亡/复活、暂停、确定性、地图生成与实体上限。使用合法操作通关全部试炼、多种种子的长距离无尽，不能修改生命或障碍来声称通关。
3. 存档测试覆盖货币结算去重、购买/装备/升级、日期边界、任务/成就、存储失败以及刷新和原生重启。
4. 实际 Creator 导出三个目标，校验引擎来源、资源完整性和小游戏包预算。原生宿主执行真实 game.js，验证没有 DOM 的启动、触摸、后台暂停、恢复、重启和渲染。
5. Web 至少覆盖 390×844、320×568、1440×900、844×390；实际键盘/触控、菜单、教学、主局、试炼、暂停、死亡/再玩、商店、截图、页面错误和返回大厅。
6. 九款游戏整站 `pnpm check`，统一发布到 gh-pages；核对线上 release.json、九个入口与大厅。完成后关闭本轮服务和浏览器。官方平台工具、真机和上传审核未实际执行时如实标注。

实现按规范、游戏核心、美术与交互、三端验收和大厅集成拆分提交。
