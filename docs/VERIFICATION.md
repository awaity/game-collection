# 工作区迁移验证

日期：2026-10-16。验证基于 Node.js 22.23.2、pnpm 11.23.0；完整站点在 `/game-collection/` 子路径下运行。

## 自动检查

- `pnpm install --frozen-lockfile` 成功；大厅和两个游戏共用根目录 `pnpm-lock.yaml`，均未保留 `package-lock.json`。
- `pnpm check` 通过：Vue / TypeScript 检查、全部 Web 构建、31 项测试（弹幕小队 12、尸潮防线 13、站点 4、小游戏宿主 2）。
- 静态站点检查涵盖两款游戏、14 个 HTML / CSS 资源引用、子目录部署、封面、返回大厅入口、刷新、目录末尾斜杠与 404。
- 微信、抖音实际 `game.js` 在没有 DOM 的模拟宿主中启动，能创建画布和接收真实触控事件；平台工程包正常生成。
- 对照迁移前提交检查弹幕小队源文件：战斗逻辑、渲染、模型、测试和 Sites 包装内容一致，仅启动错误提示中的包管理命令改为 pnpm。
