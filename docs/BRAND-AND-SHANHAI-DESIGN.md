# 开局游戏品牌与山海美术升级

2026-10-19。统一九款游戏的品牌与入场交互，替换默认 Cocos 开场；优化山海逃亡的界面、行者、五套衣装和动作特效。规则、关卡与存档继续共用原实现。

## 视觉方案

- 品牌标识：门形笔画结合播放三角，表达「开门、开局」。自绘矢量，不使用通用手柄图标。完整名称统一为「开局游戏」。
- 品牌色：开局紫 `#6254C7`、夜蓝 `#292943`、云白 `#F5F5FB`、星橙 `#FFB46B`、淡紫 `#E7E3FA`。沿用大厅已有紫色，橙色只点亮播放符号。
- 字体：品牌字标与交互使用中文无衬线粗体；山海标题使用中文衬线，数字与正文使用无衬线。正文至少 13px，主要触摸操作至少 44px。
- 入场：居中标识与游戏名称，资源就绪后开门揭幕；可轻触/键盘跳过。只在初次加载出现，局内重开不重复。加载失败提供明确恢复操作，不显示虚构百分比，减少动态时直接淡出。
- 山海：深青 `#153D3B`、玉青 `#67B9A5`、纸金 `#F3E6C6`、鎏金 `#E9BC64`、朱砂 `#CE6953`。人物采用更细致的多边形面部、发束、交领、护肩、腰带、衣摆、鞋靴与连续飘带。
- 五套衣装保持已有 ID 与价格，增加狐尾/狐火、层叠羽翼/羽光、毕方翼冠/火羽、月轮/星轨；特效随动作和装扮变化，低画质减少粒子，减少动态停用装饰运动。

方案自查：标识使用「开」的门形笔画而非现成手柄；启动动效只承担状态过渡。山海的辨识度来自人物轮廓、衣料层次与山海法术，避免把改色当作新皮肤。菜单保留中央角色展示区域，行装提供购买前预览，不用弹窗文字遮住角色。

验收覆盖九款 Web 入场、移动/桌面/横屏、跳过与减少动态、加载错误恢复；微信和抖音验证原生绘制及输入隔离。山海执行原有规则与三端流程，并查看五衣装、动作特效、主菜单、行装和小屏截图。统一发布并关闭本轮服务。
