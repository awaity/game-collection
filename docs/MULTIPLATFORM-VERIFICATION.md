## 关键回归

- 花园守卫：原有十二关、五场冒险、有限/无尽挑战、存档和键盘/触控；原始同级项目保留。
- 最后一道门：三路线 18 个原版状态哈希、真实射击/成员/补给/首领伤害、输入回放与挑战链接；演示结果不伪造胜利或写入手动纪录。
- 电涌小队：三章 21 个原版检查点、有限电量、最近目标射线、金色电站解锁、实际命中和结算。
- 雪原小营：24 个原版存档检查点、九个连续世界操作检查点、四种终局；商队安全/遇袭使用固定随机输入覆盖两种结果，生产规则未变。
- 无尽长夜：六场景 36 个完整状态哈希、四角色、血月/连战、一次扣减/结算、解锁与存档；三端另跑六场景开局升级、技能与物品，验证分包及音频请求。
- 飞机大战：三档难度、五级火力、补给上限、护盾、Boss 弹幕/结算、无限压力推进；一弹单目标、击杀只计分一次、四边清理弹幕；30/60/120 Hz 仿真结果一致。
- 飞机大战生命周期：零坐标、触摸取消、暂停不推进计时、后台/前台无追帧、重开无重复监听或 RAF；设置容错、同源旧高分一次迁移且保留原键。
- 尸潮防线：原有标准/硬核通关输入与战斗测试保留；本次没有修改 `src/core`。
- 弹幕小队：三条原路线的精确结果、回放一致性、v1 记录兼容保留；模拟、五个模型、Sites worker 均未改变。模型检查限制外链 buffer、图片和新增必需扩展，防止素材更新绕过原生适配。
- 返回大厅：游戏显式报告状态；修复 Canvas 在 pointerdown 暂停后，同一触点松开可能误点新出现的返回链接。返回入口等当前手势及 click 结束后显示，触屏测试覆盖该路径。Cocos 菜单翻页及视口变化时，返回入口根据可见控件边界重新选位，避免遮住分页和游戏按钮。
- Web 键盘：Creator 从语义按钮开始、恢复或释放技能后，焦点回到 GameCanvas，真实方向键移动经过物理和碰撞计算。

## 可重现命令与证据

```bash
pnpm install --frozen-lockfile
pnpm cocos:install  # Windows / WSL，macOS 安装步骤见 COCOS.md
pnpm exec playwright install --with-deps chromium
pnpm check
```

- `artifacts/eight-game-check.log`：本轮根目录 pnpm check 完整日志。
- `artifacts/native/report.json`：四款非 Cocos 游戏的八个原生包大小、宿主流程、截图。
- `artifacts/web/report.json`：页面宽度、游戏流程、手机与桌面截图。
- `artifacts/cocos/`：四款 Creator 游戏的四视口/两原生宿主报告和截图；无尽长夜 `content/{web,native}.json` 是额外六场景检查。
- 各游戏 `docs/VERIFICATION.md` 和根 `design-qa.md` 记录规则、视觉来源与对照边界。
- GitHub Actions 归档 `site-<SHA>`、`all-games-mini-<SHA>`、`verification-<SHA>`。
- 自动测试使用临时端口，成功或失败均关闭浏览器和 HTTP 服务；任务结束另确认常用预览端口已释放。

本地已有浏览器可通过 `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH` 指定路径。共享库缺失时应安装 Playwright 系统依赖；仓库不硬编码本机浏览器或动态库路径。

完整站点发布由根目录 `pnpm run deploy` 执行，`gh-pages` 提交与线上 `release.json` 标注源代码 SHA。官方小游戏上线仍按 [PLATFORMS.md](PLATFORMS.md) 的独立流程执行。
