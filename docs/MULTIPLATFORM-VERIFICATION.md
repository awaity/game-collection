原生包检查包含工程类型、本地音频和保守的 4 MiB 主包/分包、20 MiB 总包预算。无尽长夜按公共素材、六场景、音频和 WASM 分包，原生物理从静态代码分包加载。音频 API 在 Worker 宿主中由桩实现，只检查调用链和资源；实际播放、解锁和听感仍需平台工具/真机验证。

弹幕小队的基础原生检查覆盖微信 WebGL1、抖音 WebGL2；新增成长原生流程使用 WebGL1。Creator 宿主运行官方适配器和真实 WebGL。浏览器流程选用弹幕小队轻量画质。专用 Cocos 回归暂停自动绘制，通过官方 `game.step()` 呈现输入后的帧，再用 QA 接口推进真实规则。成长原生检查按最多八帧分批推进，每帧仍真实绘制，避免软件 WebGL 单次请求超时。这些调度不改变生产画质，也不代表真机性能数据。

## 本轮内容与成长验证

- 花园守卫：18 植物、15 僵尸、六章 24 关、12 种挑战。24 关与 11 项有限挑战均以合法收集、种植、铲除策略通关；保留五场冒险与原冰火、抛射、回旋、闪电回归。新增磁力卸甲、邻格治疗、整行烈焰、穿刺防空、矿工后场进攻、鼓手加速、雨林冷却和露台障碍。无尽开放全部植物，清波补给只发一次；普通关卡波次不累计无尽任务。
- 花园交互：390×844、320×568、1440×900、844×390 的生产包检查包括三袋种子、挑战/图鉴分页、八项专项挑战真实胜利、自然波次冰封截图与旧存档。原生宿主以真实触控翻到第三袋后返回种植。
- 电涌小队：六张地图，新三图用正常走位真实击败双首领；原三章 21 个状态检查点保持。无尽接战保留队员并补员、轮换地图和增加压力。实际子弹、激光伤害与攻击间隔接入强化；演示及演示接管不发金币。
- 最后一道门：六条路线，新三路线真实胜利，原三路线 18 个状态哈希保持。无尽只有击败首领才接战，超时不发通关奖。成长与接战人数写入新版回放，旧版兼容；火力造成的小数耐久在界面上取整显示。
- 弹幕小队：六条路线，新路线与新强化回放结果一致，旧三路线精确结果与 v1/v2 回放保留。无尽接战保留队员并补员。五个本地模型与 Sites 包装保留，玩家制服顶点颜色随所购皮肤变化。
- 飞机大战：四大空域、12 任务均在标准难度、无购买升级、无恢复生命时真实通关。风、精英、补给和首领节奏随空域变化。无尽每 30 秒增加压力并轮换地图，实体数量有上限。装填一级即提高实际发射次数；生命、子弹伤害、连续过关与直接选关的一致性均覆盖。
- 成长：新存档签到 125 金币、重复签到不再加钱；购买一级强化扣 100，余额 25；刷新/原生重启保留。商店与任务用明确的余额和进度夹具验证购买、免费重装备、分页、任务/成就领取。随后从真实入口出战，验证已购皮肤和强化确实进入战斗；同时校验已领奖励和地图首通记录在重载后保留。
- 金币结算：累计计数与持久化对局序号防止重复奖励；旧对局回调不能写入新局。三款小队的 Web 流程使用合法走位真实赢得无尽首波，核验只发一次金币，再通过按钮进入第二波并保留队员。存储失败会回滚购买与奖励。

商店夹具不作为自然通关证据；飞机的长时间实体上限压力测试会恢复生命，与标准难度真实通关测试分开记录。关卡策略只用普通游戏操作，不修改生命、伤害、敌人或通关标记。

## 可重现命令与证据

```bash
pnpm install --frozen-lockfile
pnpm cocos:install
pnpm exec playwright install --with-deps chromium
pnpm check
```

- `artifacts/expansion-check.log`：本轮根检查日志。
- `artifacts/growth/{web,native}-report.json` 和同目录截图：五款游戏的新成长、商店、地图、无尽和重载验证。
- `artifacts/native/report.json`：四款非 Cocos 游戏的八个原生包、宿主流程与截图。
- `artifacts/web/report.json`：大厅、全站入口、返回及手机/桌面截图。
- `games/garden-guard/artifacts/web-verification.json` 和同目录截图：四视口、三袋种子、冰封、原挑战与四项最新挑战结果。
- `artifacts/cocos/`：四款 Creator 游戏的四视口/两原生宿主报告和截图；无尽长夜 `content/{web,native}.json` 记录额外六场景检查。
- GitHub Actions 归档 `site-<SHA>`、`all-games-mini-<SHA>`、`verification-<SHA>`。

本地已有浏览器可通过 `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH` 指定。缺少系统共享库时安装 Playwright 依赖；仓库不硬编码本机路径。检查脚本在结束时关闭浏览器和 HTTP 服务，交付前另核对本轮预览端口与进程已释放。

完整站点由根目录统一发布，`gh-pages` 提交与线上 `release.json` 标注源码 SHA。金币和装备按游戏保存在本机，无跨设备云同步。官方小游戏上线另按 [PLATFORMS.md](PLATFORMS.md) 执行，网页发布不等于微信/抖音平台上线。
