# 向僵尸开炮复刻实施与验收

目标：完整复刻《向僵尸开炮》的射击塔防与局内成长体验，独立加入 `games/zombie-fire`，支持 Web、微信小游戏、抖音小游戏。此清单用于跟踪完整目标，极简闭环只作为中间里程碑，不能据此标记完成。

## 参考与一致性

2026-10-19 采集官网 `https://xjskp.scgame.com.cn/`、六张官方展示图和公开技能说明。官网展示了竖向尸潮、底部防线、自动枪械、经验升级、三选一卡牌、装备/宝石/佣兵、首领与持续闯关。另已只读提取官网公开安装包的部分配置，确认分类和表结构；核心技能/关卡表尚未完整解析。原版可交互客户端与线上赛季服务尚未实际运行；宣传图与静态配置不作为实际试玩证据。详见游戏的 `docs/REFERENCE.md`，后续持续补齐差异矩阵。

## 完整功能清单

1. 固定底部防线，敌人自上而下推进并持续攻击；自动瞄准、换弹、穿透、弹射、范围爆炸和伤害数字。支持手动点选优先目标。
2. 击杀经验、升级停战、三选一技能、合法前置条件、刷新次数、技能槽位、局内等级、技能分支与组合进化；选择影响真实攻击，不能只改面板数字。
3. 温压弹、干冰弹、电磁穿刺、制导激光、高能射线、冰暴发生器、旋风加农、燃油弹、跃迁电子、压缩气刃、装甲车、空投轰炸、无人机、时空裂隙、生化矩阵、冰筑龙体、电极柱、多维弹球及枪械分支。逐项记录来源与未核实参数，不将未知技能从完整范围中移除。
4. 普通、迅捷、护甲、护盾、远程、治疗、分裂、飞行、自爆、元素抗性等敌人；带预警和不同技能的首领；烧灼、冻结、麻痹、击退、重伤与抗性相互作用。
5. 主线逐关解锁、地图变化、明确波次、精英与首领、三星/最佳记录、可重玩结算；无尽压力增长、地图轮换、每日挑战与独立奖励。2026-07-28 官方公告已确认扩展到 409 关、400 关起有子关卡技能锁定；当前最新总量和精确配置仍待核验，不将自编配置声称为原版数据。
6. 局外金币/钻石/材料、枪械与防线升级、六槽装备、宝石镶嵌与合成、佣兵招募/出战/升级、时装、技能研究、任务、成就、签到、补给与存档；奖励和购买持久化、重复结算防护、存储失败回滚。
7. 原版战斗构图和工业漫画风格：尸潮占据主画面，顶栏经验/波次，侧边技能状态，底部堡垒与枪口；升级为三张档案式卡牌。角色、场景、技能图标、音频采用原创资源，参考图仅存忽略目录。
8. 初次教学、暂停/恢复/重开、设置、图鉴、技能组合说明、成长界面与返回大厅；移动优先，320×568、390×844、844×390、1440×900 四视口；键盘、触摸、安全区、减少动态、音量、低画质。
9. Cocos Creator 3.8.8 官方三目标导出，共享平台适配，统一开局游戏入场。核心规则无 DOM/wx/tt，固定步长与确定性随机。原生包预算、资源来源清单、浏览器及双原生宿主实际运行。
10. 完整内容验收、参考差异审查、大厅封面与介绍、根目录全站验证、源码上传和 gh-pages 发布、线上版本/入口检查，最终关闭本轮服务。

原版社交、组队、竞技、赛季与账户服务也在参考差异清单中保留。需先核实实际行为和所需服务条件，不能用假联网按钮、机器人排行榜或静态占位称作完整复刻。

## 实施顺序

- 先建立独立工程、确定性战斗与升级选择，跑通一场真实胜负及三端启动。
- 然后补齐技能树、敌人/首领、关卡、无尽、局外成长和完整菜单。
- 完成原创美术与音频、四视口截图对照、性能边界和跨端全流程。
- 按完整清单审计缺口，再执行统一发布；只有所有要求有直接证据才能完成目标。

## 2026-10-19 实施进度

独立工程已经具备固定防线、真实弹道和元素状态、十九类武器、一百二十四项升级（二十八项进化）、十七种敌人、三首领、六地图、三十六个本地配置关卡、无尽及四种本地每日规则。金币/钻石/零件、六件五孔装备、宝石、佣兵、研究、五时装、签到和任务已接入实际战斗与原子存档。原创绘制、合成音频、分页成长界面、分类图鉴、三选一卡牌、设置和共享入场已实现。

新增电极柱顺次连线的实际碰撞，以及多维弹球的目标/墙壁反弹、二十种幸运值词条、延迟连发、无强化裂变球和21点进化。原版赛季核心解锁、感电及赛季宝石仍留在差异清单。

后续静态核对已还原100,613条完整文本，解析4,959条卡牌定义的边界，并识别6,196条选卡组记录。已发现当前弹球幸运增减和部分效果沿用旧攻略，与本次客户端配置有差异。独立离线读取器及证据边界见 `games/zombie-fire/docs/REFERENCE-TABLE-SCHEMA.md`；当前阶段不把已解出的定义直接等同于普通卡池，优先核对模式引用、研究条件及隐藏分支后修正玩法。

按已核验的定义修正二十项弹球幸运区间、弹球浪潮的+2弹射和阻滞的加速限制。可见卡片显示本张幸运增减与选择后点数，选择按显示值结算；闭区间取整数和选项生成时取值为本地选择，原版取值时机仍待实测。普通卡池、10/21点门槛、完整研究及隐藏卡仍未还原，详细证据与本地参数分别记录。

幸运弹球已根据公开安装包的行为资源接入：每6次主技能施放触发，100:50:10三品质、准备阶段、持续穿透和墙壁反射、中品质衍生光球、高品质追加爆炸，以及四项终极词条的独立强化。十四张表和2,804个行为资源名称已做结构检查；伤害基数、坐标映射和生命周期解释仍明确标记为本地选择，见 `games/zombie-fire/docs/LUCKY-ORB-REFERENCE.md`。普通球8秒、裂变3.5秒寿命及0.5秒连发/重复命中间隔已接入；边界反射已与3次敌人转向预算分开，修正真实路径碰撞、远距离转向及裂变尺寸/速度比例。反射枚举、事件调度和目标排序仍待原客户端核验，21点隐藏词条及其余分支仍需继续还原。

技能基础表已核对2,153条完整记录及十八类引用；技能等级表828条记录全部对齐，包含18类各1–46级的静态序列。研究说明进一步关联弹球的选项解锁、初始幸运及次数保留概率，也区分了同名卡牌和冰龙普攻/技能冷却。该研究只补充证据，尚未改动游戏中的本地研究和卡池，完整模式引用、属性合并及客户端实测继续保留为待办。

无人机的反弹重复命中、裂隙的菱形伤害/状态延时/传送/纠缠、矩阵融合与逐步禁锢，以及机械冰龙的索敌爪击/满能量坠击均已接入规则。四技能的公开来源与调校边界见配置研究记录。新增漫画敌人绘制、技能实体、范围与预警、档案纸卡片，视觉方案及自查见游戏的 `docs/VISUAL-ITERATION.md`。

官网明确的四类时装命中触发机制现已加入：温压追加齐射、双段等离子场、冰风暴、三连气刃。HUD 显示充能与触发次数，图鉴包含效果及计数规则。触发阈值和公开倍率有官网文字依据，其他调校参数在 `games/zombie-fire/docs/OFFICIAL-CONFIG-RESEARCH.md` 单独记录。

已执行规则/存档测试和从空存档开始的三十六关合法成长审计，并进行 Web 四视口与双原生宿主的实际导出验证。最终检查结果和证据路径另记于游戏的验证记录，不以“成功构建”代替运行验证。

完整目标仍在进行中：原版可交互客户端、完整数值/成长/关卡、视觉一致性和线上玩法尚未核验；官方开发者工具与手机真机尚未运行；大厅集成、整站回归和新游戏发布尚未进行。当前内容是可运行的独立重建阶段，不将本地原创配置、几何绘制或模拟宿主流程等同于完整复刻。
