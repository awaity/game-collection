# 游戏大厅设计依据

已确认的目标：多个小游戏的统一入口。Vue 3 + Vite + TypeScript；移动端优先，同时支持 PC。使用现有两款游戏的真实运行画面、名称、玩法与操作说明。

色板：雾紫白 #f5f5fb（页面底色）、墨蓝 #292943（正文）、鸢尾紫 #645ac8（按钮）、浅蓝 #dceafa（小队游戏）、鼠尾草绿 #dce9dc（僵尸游戏）、暖黄 #f2ca76（小面积提示）。

字体：中文系统苹方/微软雅黑，标题粗体、说明常规体。标题不依赖远程字体。卡片左对齐，移动端大按钮与不少于 44 px 点击区域。

布局：顶栏品牌和游戏/说明/GitHub；简短标题；两款游戏实机封面与介绍；可以展开的玩法说明；底部简短操作指引。手机单列，PC 双列。画面占据主要空间，打开游戏前不加载任何游戏引擎。

```
手机：品牌         GitHub     PC：品牌                  导航
      标题与简短介绍              标题与介绍
      尸潮防线实机画面            尸潮防线         弹幕小队
      介绍 / 玩法 / 开始          截图与操作       截图与操作
      弹幕小队实机画面            操作指引与页尾
      介绍 / 玩法 / 开始
```

复核：两张卡片对应两款真实游戏，结构重复有助于比较。无需后台式统计、虚构热度、登录或复杂搜索。第一屏突出实际游戏内容；封面从运行画面截取而非生成不存在的玩法。
