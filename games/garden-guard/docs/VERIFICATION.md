## 命令与结果

- `pnpm --filter garden-guard test`：27 项通过，覆盖全部关卡、五场冒险、七项有限挑战及新增机制。
- `pnpm --filter garden-guard build:all`：TypeScript 严格检查、Web、微信、抖音构建成功；两个小游戏工程各约 190 KiB。
- `pnpm --filter garden-guard verify:mini`：两个实际 game.js 在没有 window/document 的 API 合约宿主内通过启动、触控、生产/收集、存档、后台暂停、挑战翻页、无尽新植物种植和图鉴验证。
- `pnpm --filter garden-guard verify:web`：生产包在 390×844、320×568、1440×900、844×390 四种视口完成菜单、触控/键盘种植、暂停/恢复、通关和刷新后解锁验证；新增挑战与图鉴分页、无尽种子袋、实际冰封和持续波次已覆盖。正常 URL 无 QA 接口。
- 根目录 `pnpm check`：发布前完整运行，结果汇总于根 `docs/MULTIPLATFORM-VERIFICATION.md`。

根 `verify:web` 已纳入本游戏专项检查。根 `verify-native` 另在浏览器 Worker 的无 DOM 宿主执行实际微信/抖音包，以真实 Canvas 绘图验证新增挑战、种子翻袋、三线/寒冰种植和新增僵尸图鉴；截图和结果存入根 `artifacts/native/`。

## 验证边界

关卡、挑战、无尽实战策略只使用正常种植、铲除、收集和时间推进，不注入阳光、生命、敌人或通关标记。单元测试针对冻结、护甲等边界单独构造敌人；冰封截图来自自然波次。

微信和抖音通过原生 Canvas 运行，共用规则/绘制，不使用 WebView。模拟宿主通过不等同于官方开发者工具或真机通过。尚未使用真实 AppID 执行开发者工具导入、iOS/Android 真机、平台登录、上传、审核和上线；本轮发布目标为 GitHub Pages。步骤见 [PLATFORMS.md](PLATFORMS.md)。

Chromium 真实 Canvas 与触控模拟已验证；音频 API 合约检查覆盖调用和本地 WAV 资源，微信/抖音实际音频听感、GPU/内存性能和实体设备安全区仍需真机验收。缺少系统共享库的 Linux 环境通过 Playwright 系统依赖或环境变量指定已有浏览器依赖，仓库不硬编码本机路径。
