## 命令与结果

- `pnpm test`：16 项测试通过，包括 12 个关卡、5 场冒险、3 项有限挑战的实战验证。
- `pnpm build:all`：TypeScript 严格检查通过；Web、微信、抖音三个产物生成成功。
- `pnpm verify:mini`：两个实际小游戏包各自通过无 DOM 启动及原生触控集成验证。
- `pnpm verify:web`：四种窗口尺寸通过；冒险升级／刷新、挑战纪录与无尽波次验证通过。详细报告在 `artifacts/web-verification.json`。

本次精简 WSL 环境使用已存在的 Chromium 共享库目录执行浏览器验证：

```bash
LD_LIBRARY_PATH=/tmp/weread-browser-deps/root/usr/lib/x86_64-linux-gnu pnpm verify:web
```

这是验证环境配置，不是游戏运行时依赖；在系统库完整的机器上直接执行 `pnpm verify:web`。

## 范围与限制

参考策略只使用正常种植、铲除／收集和时间推进，没有注入阳光、生命或通关标记。测试中针对爆炸、减速、失败等边界的单元场景会单独构造敌人，但全关卡实战和浏览器通关均由正常波次驱动。

平台合约模拟验证不等同于官方开发者工具或真实手机验收。当前未提供平台 AppID，且环境中未安装官方微信／抖音开发者工具；因此未进行平台登录、上传、审核、发布，也没有把模拟测试称为真机测试。导入工程和真机验收步骤见 [PLATFORMS.md](PLATFORMS.md)。

浏览器验证使用 Chromium 的真实 Canvas 与触控模拟，没有覆盖每个浏览器版本、实际 iOS Safari 或实体 Android 设备。运行代码仅使用常规 Canvas 2D、Pointer Events 和标准本地存储接口。
