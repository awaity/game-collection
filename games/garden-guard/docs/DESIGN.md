# 花园守卫设计

植物大战僵尸的五行九列策略塔防：阳光、种子卡、分路防守、割草机与波次。角色、场景、声音以代码重新绘制和合成，全部资源随工程分发。

## 视觉计划与复核

配色：深苔绿 #143e32（文字与轮廓）、叶绿 #75b945（草坪）、浅芽绿 #b9d879（植物高光）、阳光黄 #f8ca58（资源与主按钮）、木棕 #976342（边框）、纸白 #fff5d6（种子卡与说明）。字体：系统圆体优先，回退 PingFang SC / Noto Sans CJK SC / sans-serif；标题粗体、正文中等、数字清晰。

主视觉是一块有栅栏、小屋、植物和僵尸的真实花园场景。首页桌面左侧标题和三种模式，右侧完整花园插画；手机竖屏上半屏标题与花园，下半屏三种玩法入口。入口形态是木牌和种子袋。游戏页使用顶部资源与种子卡、中央占满宽度的草坪、底部铲子/倍速/提示。所有画面在原生 Canvas 中完成，共用触控命中区域。

复核：不使用通用管理后台、霓虹面板或以同构卡片堆叠首页；风格依据花园、木牌、种子袋与草坪。角色拥有统一粗轮廓和软阴影，可读性先于装饰。常规竖屏主要按钮至少 44px，较矮窗口按可用空间缩放；手机草坪格子窄于按钮，采用高行距与触点定位高亮。移动端无需强制横屏，电脑支持鼠标和键盘。支持静音、自动收集阳光、减少动态效果，浏览器首次进入遵循系统的减少动态效果偏好，切后台自动暂停。

## 内容

- 关卡：三章十二关，初晴庭院、月光花圃、薄雾林地，逐关解锁和三星纪录。
- 冒险：五场连续战斗，关间三选一升级，支持保存当前关的出发点。
- 挑战：限量阳光、极速尸潮、坚果防线、无尽守卫，独立最佳纪录。
- 八种植物与六种敌人，图鉴包含费用、特点和应对方式。
