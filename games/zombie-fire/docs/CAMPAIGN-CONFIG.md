MonsterCfg的SHA-256为`691e8cda216bd1fb3025950118a4d055e2823143c1ab3cbe13db03af3fd9c713`；MonsterManualCfg为`29a5d955f39c76a27331a55de7464a54f9b6443841ee1a40b2d280f541203cf9`。

波次集合按文件名中的数字排序，每项以UTF-8编码的`文件名 + NUL + SHA-256小写十六进制 + LF`组成，整体SHA-256为`47b4d347884fdac88681ca6fac2ba132f1d611eaeafb8792634f55e74658d1b0`。所有文件头第五字段均为9999；只核对该字面值，不声称已证明其校验算法。原始表及生成报告只保存在忽略目录。

## 必须保留的例外

- 82,631条波次的偏移33为0。其动态库或事件语义未确定，不能生成“0号怪物”，也不能直接删除这些记录。
- 42个文件的记录ID不连续，但各文件内部ID仍唯一。39个文件的偏移16浮点值不单调；所有值均有限且非负。读取器保留原顺序和编号，未自动排序或补号。
- 2007中第7/8条记录的偏移16分别为39与1，对应怪物20与6002。不能仅因该字段像秒数，就断言所有模式都使用从开局计时的绝对时间。
- 图鉴330的偏移4为0，302/303为1，均不对应完整怪物ID。另有18条图鉴ID与偏移4不同，不能直接用图鉴行ID替代该字段。
- 26条完整关卡记录没有同ID的波次文件。其父节点、活动或其他入口语义仍待查，不补造波次。
- 13142/13242的名称分别省略了编号314-2/324-2之后的句点。按实际编号核对说明，单独记录这两项格式例外，不修改参考文字或排除对应子关卡。
- 16条子关卡的名称与说明编号冲突，例如13254的名称为“325-4.暗渠逃杀”，说明为“第323-4关”。读取器分别保留名称、说明、文本引用及两个编号；没有把任一字段覆盖为另一个字段。

偏移12、16、41分别保留为波次编号、时间、数量的候选；偏移8和字节24也存在多种值，条件枚举仍待追踪。1001的36条记录包含20个不同的偏移12值，其前三条偏移16为0、6、15；这说明本地统一波次公式尚未还原此配置，不证明原版所有关卡固定20波。

## 复核与后续

本次完整读取命令已成功退出。另通过四项失败路径检查：缺少一份波次、波次截断、结构仍有效但版本指纹改变、怪物表版本指纹改变；均被拒绝且保留原成功报告。读取器源码指纹、输入指纹、命令退出码和发现阶段的两次失败记录见 [CAMPAIGN-VERIFICATION.json](CAMPAIGN-VERIFICATION.json)。本次未启动游戏服务，临时验证输入已移除。
