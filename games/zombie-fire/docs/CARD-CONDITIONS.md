2026-10-20。依据官网公开安装包的完整配置记录，继续修正本地弹球树。没有运行原版客户端；以下区分静态引用、本地采用的规则与未知调度。

## 关卡字段与库、组的引用

独立读取器 `tools/inspect-reference-tables.py` 新增 `levelLibraryCandidates`。`LevelBaseConfig` 最后159字节块的偏移28是一个大端u32；13,013条完整记录中，13,006条的该值对应完整 `BuildLibraryConfig` 的首字段，6条为0，唯一非零未对应项是关卡91001的31。

库表231条完整的库/组对互不重复，全部对应完整组选卡记录，涉及18个库。关卡1001/2001的候选值均为2；库2连接组2001和21个辅助组。库1则连接1015等19个组。此处只报告引用，不把字段命名为已经验证的运行时派发，也不把所有链接组同时放进选卡池。

库表首条不完整记录起于1868，其第一个完整u32也是31；第二字段跨越未解码边界，因此整条仍排除。不能用这个局部匹配补齐关卡91001的分组，也不能将其计入13,006条已匹配记录。

`orbGroupComparisons` 对比1015、2001、3001、4001、5001、6001、11000、102001、310000九组各25条弹球定义。前八组的次数候选和前后段条件一致，但权重候选并不完全一致：相对1015，2001中的1508、1509、1514分别是60/60、30/30、50/50。310000还有次数和条件差异，其模式未确定。

| 分支 | 静态证据 | 接入的规则 |

| 动能爆破1510 | 前八组均要求1501和1506 | 先获得弹射裂变，再满足本地幸运门槛，才进入候选 |

| 分支 | 原本地上限 | 修正后 |
| --- | ---: | ---: |
| 低维增伤 | 4 | 3 |
| 低维弹射、升维、急速弹射 | 各3 | 各2 |

这是选定共同配置作为本地规则的解释，仍不是客户端运行证据或所有原版模式的通用上限。升维与升维+共用稳定ID及次数，研究替换不增加额外次数。新条件同时约束候选生成和选择结算，过期或不合法选项不能部分扣幸运、增加等级或改变伤害。

战斗在入场时捕获研究；购买与读档规则不变。研究、图鉴说明同步显示6级升维和10级浪潮的条件，图鉴补充裂变前置与次数上限。成长列表使用独立的文字和按钮区域，保留8px间距，避免320px宽度下成本文字与按钮相交。

## 保留的缺口

- 组1015/2001中的弹球重击、动能爆破、阻滞和终极/隐藏分支存在零权重候选；原版动态改权、选卡组切换与模式派发未验证。本次没有将静态权重照搬为最终概率，当前普通池仍有本地重建成分。
- 隐藏组2002包含1518–1521、1524、1553，不包含钢珠机1522与动能强化1523。Buff类型84的子类型7、21点触发后的授予/选择过程仍未知；本次没有添加猜测的隐藏选卡界面。
- 等级2说明指向“致残撞击”，而普通组的研究2条件位于阻滞1512；等级14说明指向“超武装”，普通组研究14条件位于动能强化1523。保留冲突，没有按名称猜测解锁。
- 钢珠机序列化位置包含z偏移8、`m_fixXByEnemyPos=1`、`m_down=1`、角偏移25，与从上方落下的文字相符；坐标/技能生效范围和解锁入口尚未核验，仍未加入玩法。

规则测试检查9/10级和20/21点边界、实际额外弹道/轮数、两项裂变前置，以及次数耗尽后的过期选项拒绝。导出流程保留已有28项检查，新增普通奖励购买到研究10级、可见选择弹球浪潮、真实多球攻击及重载，并逐次检查实际选卡的前置与次数。执行结果记录于 [VERIFICATION.md](VERIFICATION.md)，不以测试定义代替已执行证据。
