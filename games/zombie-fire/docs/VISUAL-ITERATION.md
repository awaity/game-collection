# 原创战斗绘制迭代

2026-10-19。对照官网展示图的竖向尸潮、粗描边角色、档案卡片与工业街道；官网图是宣传素材，不作为已试玩或逐像素匹配的证据。生成源仍为 Cocos Graphics / TypeScript，不引入原版图片。

## 实施前方案

- 配色：轮廓墨黑 `#172029`、混凝土蓝灰 `#66717d`、火力橙 `#f39626`、经验蓝 `#49b7ef`、档案纸 `#e9dfc6`、感染灰绿 `#9fb7ab`。技能保留独立冰、电、毒色，背景降低饱和度。
- 字体：Noto Sans CJK SC / 系统中文无衬线。主标题粗体，说明正常字重；卡片正文在手机保持可读，等级与伤害数字有独立的大小层级。
- 构图：保持上方经验和波次、右侧技能、底部防线。尸群使用较大的头部与手臂轮廓，服装折痕和脸部阴影帮助识别。弹道和技能范围从世界坐标投影，横屏不得用压扁的装饰圆替代真实碰撞区。
- 卡片：档案纸、方格底纹、齿轮技能章、折角和明确的“新技能 / 进化 / 等级”标签。三张卡保持等宽等高，选项名称和说明居中；文字不能被纹理干扰。
- 技能：无人机有旋翼和移动方向；裂隙是明确的菱形并显示纠缠线；矩阵是能融合的毒液和束缚；机械冰龙有实体躯干、爪击、能量条和坠击预警。爆炸增加放射碎片，电击有分叉，冻结有冰棱。

```text
┌ 暂停       波次 / 时间       等级 ┐
│════════════ 经验 ══════════════│
│       裂隙 / 机械冰龙       技能 │
│      服装区分的尸群        等级 │
│       弹道 / 范围预警            │
│ ▧▧▧▧▧▧▧▧▧ 堡垒 ▧▧▧▧▧▧▧▧▧ │
└             防线 / 弹匣          ┘
升级：暂停背景 → 三张纸质档案卡 → 选中后继续
```

自查：本次不再用统一圆环表示所有持续技能，也不通过不同颜色代替敌人轮廓。记忆点放在尸群与技能交互；周边菜单不增加无意义动画。低画质减少细节和粒子，减少动态停用旋翼装饰、闪烁与游走纹理；技能必要位置、范围和预警仍可见。
