# 官方配置的只读核对

2026-10-19，从[官网](https://xjskp.scgame.com.cn/)的公开下载入口取得 Android 安装包地址：

`https://cdn.xhgamesdk.com/pack-ad/plan_url/1100/9002/ec93ae3836a5d2712ffb0a98b07fe941.apk`

安装包为 1,840,181,435 字节，ZIP 中央目录包含 19,903 个条目。使用 HTTP Range 读取中央目录和选定的游戏配置；服务端必须返回 206，读取长度有上限。未下载整个安装包，未执行原版代码，未读取 SDK 凭据或将原版资源放入发行目录。

资源采用 UnityFS；所选 bundle 的版本头为 Unity 2021.3.30f1。使用隔离环境的 UnityPy 1.25.0 提取 TextAsset，研究文件全部位于被 Git 忽略的 `artifacts/research/zombie-fire/`。本工程仍为独立实现的官方 Cocos Creator 3.8.8 工程。

### 文本与选卡表的后续核对

新增可复核的离线读取器 `tools/inspect-reference-tables.py`，只接受本次七个 TextAsset 的已知 SHA-256，不联网、不执行原版代码、不写入发行目录。`pnpm --filter zombie-fire reference:inspect` 读取已有研究副本并输出忽略目录中的 `validated-tables.json`。工具只返回完整16字节块，末尾4–14字节直接隔离；不把未知尾部或未核验的校验字段记作成功。结构、证据和后续工作见 [表结构核对](REFERENCE-TABLE-SCHEMA.md)。

本次读取揭示了重建的版本差异；已修正能够直接核对的幸运端点、符号及两项效果，选卡调度仍未核实：

- 多维弹球的 `BuildConfig` 1502–1525 对应到实际文本引用。高维弹射、连发、弹珠雨、致残和武装等说明使用「幸运值+{0}」，其有符号数值对为 `(8,4)`；已将旧重建的扣减改为增加4～8。终极词条从+3～5改为+1～2，其余区间详见表结构记录。闭区间整数采样和生成可见选项时固定取值是明确的本地选择；原版范围包容规则、随机时机与隐藏调度仍待实测。
- 「弹球浪潮」弹射次数从+1修正为+2；「阻滞打击」改为限制50%加速增益，基础速度不受影响，且狂暴免疫。图鉴与选卡说明已同步。
- 原表存在「钢珠机」「动能强化」「超武装」及幸运弹球相关说明；目前尚未实现。部分旧卡及终极卡在组1015中两个疑似权重字段均为0，不能用“表中存在”证明它们按普通抽卡规则出现。
- 电极柱1401–1420已关联到名称、说明及疑似技能/属性引用，能读出额外电极、麻痹、易伤、超载、超蓄、延长连线、相互连线、吸附及消失电离等分支。现有三个本地分支并不等价于这棵技能树；研究等级、互斥分支及选卡组的实际条件须一并重建。

这些是来自公开安装包的静态事实和明确的实现差异，不是客户端实测。后续继续映射当前玩法使用的选卡组，核验研究/互斥条件、随机取值和隐藏分支，重建完整局内成长。主线波次、完整成长与三端验收继续保留原范围。
