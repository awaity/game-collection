# 官方配置的只读核对

2026-10-19，从[官网](https://xjskp.scgame.com.cn/)的公开下载入口取得 Android 安装包地址：

`https://cdn.xhgamesdk.com/pack-ad/plan_url/1100/9002/ec93ae3836a5d2712ffb0a98b07fe941.apk`

安装包为 1,840,181,435 字节，ZIP 中央目录包含 19,903 个条目。使用 HTTP Range 读取中央目录和选定的游戏配置；服务端必须返回 206，读取长度有上限。未下载整个安装包，未执行原版代码，未读取 SDK 凭据或将原版资源放入发行目录。

资源采用 UnityFS；所选 bundle 的版本头为 Unity 2021.3.30f1。使用隔离环境的 UnityPy 1.25.0 提取 TextAsset，研究文件全部位于被 Git 忽略的 `artifacts/research/zombie-fire/`。本工程仍为独立实现的官方 Cocos Creator 3.8.8 工程。

## 已确认的结构事实

| 配置 | 本次观察 | 不能由此推出的结论 |
| --- | --- | --- |
| `MagicSkillConfig` | 18 条记录；图标引用包括温压、干冰、电磁、射线、载具、气刃、空投、激光、冰爆、电子、旋风、无人机、燃油、电击柱、多维弹球、时空裂隙及另外两个较新系列 | 不能把图标文件名直接当成正式显示名、完整技能行为或解锁条件；本地当前只有 12 种特殊武器，存在缺口 |
| `BattleLevelUpConfig` | 40 条记录，分两组，每组序号 1–20。第三字段分别为 `3,5,7,9,13,17,17,20,22,24,26,28,32,32,34,34,34,36,38,40` 和 `4,6,8,10,12,14,16,18,20,24,28,32,36,40,44,48,52,56,60,64` | 尚未确认分组对应的玩法、字段的增量/累计语义及最高等级处理；暂不替换本地经验公式 |
| `MonsterCfg` / `MonsterManualCfg` | 头部记录数分别为 3,210 / 207；后者含技能 ID 引用 | 记录包含变体，不能声称有 3,210 种不同敌人；未解析完整抗性/行为字段 |
| `levelwaveconfig.ab` / `levelwaveconfig1.ab` | 分别包含 11,882 / 1,105 个命名波次 TextAsset；编号从 1001 起，但并非连续的单一主线 | 不是 12,987 个主线关卡；条目包含不同模式，出怪字段尚未完整映射 |
| `ChapterConfig` | 50 条三整数记录，前几条关联 101→1001/2001、102→1002/2002 | 不能用该数量断言当前客户端只有 50 关 |

原始字节、解包清单与本地工具只用于定位参考。没有把猜测的字段排列转换成游戏参数，也没有将这些记录数作为游戏中的内容数量。

## 本轮可直接实现的官网机制

官网时装展示的可见说明提供以下事实，已接入本地原创衣装：

| 本地衣装 | 官网机制 | 已实现 | 仍为本地参数 / 待核验 |
| --- | --- | --- | --- |
| 赤焰突击 | 温压弹每命中 12 次，追加一波并列温压弹 | 独立计数、真实追加弹道与爆炸 | 一波采用三枚；发射间距和伤害继承方式未取得原版实测 |
| 极地守卫 | 干冰弹每命中 32 次，释放冰风暴Ⅰ | 在触发处生成有伤害与冻结的风暴 | 半径 76、持续 1.8 秒、每 0.35 秒造成干冰伤害的 20%、冻结 0.65 秒均为本地调校 |
| 霓虹先驱 | 电磁穿刺对同一敌人命中 2 次，电场扩散/收缩分别造成 10%/5% 电系伤害 | 每敌人独立计数、两个真实伤害阶段 | 半径 70、0.3/0.75 秒触发、0.9 秒结束为本地调校；以本次电磁伤害作比例基数待实机核验 |
| 荒野猎手 | 气刃每命中 36 次，追加三连气刃，每道 80% 伤害、重伤 50% 持续 5 秒 | 三条穿透弹道、伤害倍率和减治疗效果 | 扇形间距为本地调校 |

同一次电磁攻击的直击与溅射只计一次命中。佣兵、持续伤害与追加攻击不反复触发衣装；暂停冻结计数和效果，新对局重新计数。上述计数边界是显式的本地规则，官网文字尚不足以证明这些边界与原版完全相同。
