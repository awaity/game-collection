# 向僵尸开炮

- 完整目标与差异清单见 `../../docs/ZOMBIE-FIRE-PLAN.md`。原型仅是中间里程碑。
- 使用官方 Cocos Creator 3.8.8，独立目录，Web / 微信 / 抖音共享核心与原创美术。
- 必须是固定底部防线、向上射击、击杀升级与三选一局内成长；不能改成自由走位生存或横向跑酷。
- 规则核心不依赖 cc、DOM、wx、tt。固定 60Hz 与确定性随机，真实子弹/状态伤害、原子存档及幂等奖励。
- 参考来源、视觉对照和未知参数必须记录。宣传图不能声称为实际试玩；自编配置不能声称是原版精确数值。
- 原版图像与代码不直接复制进发布包，原创素材保留生成源。付费/联机/赛季等未实现项留在差异清单，不伪装成已完成。
- 合法输入的真实结果用于通关；QA 仅显式测试启用，不授予无敌、直接胜利或免费货币。
- 沿用 pnpm、共享平台与开局游戏入场。只由根脚本发布整站，验证结束关闭本轮服务。
- 2026-10-20 用户确认“复刻可以了，先更新看看效果”：授权将当前实现加入大厅并发布 gh-pages 供试玩。本轮以现有内容的整站接入与发布为范围，不再以原版全量等价或真机验收阻塞该次网页发布；仍如实保留参考差异和平台验证边界。
