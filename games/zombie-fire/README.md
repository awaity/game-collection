# 向僵尸开炮

独立的竖向尸潮射击塔防工程，使用官方 Cocos Creator 3.8.8。Web、微信小游戏和抖音小游戏共用确定性规则、成长存档与原创绘制。当前仍在迭代，完整目标与待核验差异见 [实施清单](../../docs/ZOMBIE-FIRE-PLAN.md) 和 [参考记录](docs/REFERENCE.md)。不能将本地配置、宣传图分析或模拟宿主检查称为原版全量等价、实际试玩或真机验收。

## 玩法

枪手固定守卫底部防线，自动瞄准进入射程的敌人；触摸敌人可优先集火。击杀获得经验，升级暂停战斗并提供三张合法技能卡。每局最多携带四个特殊技能，进化卡需要相应前置，刷新次数有限。键盘 `1/2/3` 选卡、`R` 刷新、`P/Esc/空格` 暂停；触屏直接操作按钮。

当前本地内容包括步枪和十八种特殊武器、124 项升级及 28 项进化、元素抗性及控制、十七类敌人、三种首领、六幅地图和三十六个主线关卡。主线逐关解锁，地图终章增加精英首领和首次奖励。无尽模式每八波轮换地图、持续提高压力并增加金币奖励。首领存活 25 秒、无尽普通敌人存活 45 秒后进入狂暴，挣脱控制并加速，避免无限冻结。每日试炼根据日期在疾行尸潮、重装包围、弹药精算、残垣坚守中轮换规则和地图。

无人机可撞墙反弹和重复命中，并提供枪械弹射分支；菱形时空裂隙延长控制、传送敌人并产生量子纠缠；生化矩阵能够融合、牵引和逐步禁锢；机械冰龙独立追击，以利爪和满能量后的冰狱坠击攻击。四种技能均有独立的图标、实体或范围特效，龙体能量显示在技能栏。

电极柱顺次连线，对接触电流的敌人造成伤害。多维弹球具备墙壁反射、敌人间转向和幸运值选卡，每六次主施放触发三品质幸运弹球；研究6级强化升维，10级解锁弹球浪潮。动能爆破与动能裂变需先选择弹射裂变；重复选卡受各分支上限约束。参考依据及本地参数边界见 [冷却与研究应用](docs/RESEARCH-COOLDOWN.md) 和 [选卡条件](docs/CARD-CONDITIONS.md)。

关卡、狂暴阈值、每日规则和数值均为公开机制基础上的独立配置，尚未核对原版完整配置。图鉴分别提供武器机制、进化前置和敌人规则，帮助玩家选择流派。

原版关卡研究已核对501,407条波次记录及3,210条怪物记录，识别出1–419号、683条含子关卡的静态候选序列。当前游戏仍使用上述本地关卡；动态出怪、时间派发、解锁与属性合并尚未映射，见 [关卡与怪物配置](docs/CAMPAIGN-CONFIG.md)。

营地提供枪械/防线强化、六槽装备及每件五个宝石位、宝石合成、技能研究、佣兵培养、五套时装、签到、补给、任务和成就。金币、零件和钻石通过游戏获得。补给箱展示概率，没有付费接口或模拟联网入口。佣兵等级、研究和装备属性会进入实际战斗。

四套进阶时装有真实的命中触发能力：赤焰追加温压齐射、极地释放冰风暴、荒野追加三连气刃、霓虹生成双段电场。战斗底栏显示充能和触发次数，图鉴的「时装」页说明条件。触发阈值依据官网文字；范围、时序和部分效果参数仍是本地调校，来源及边界见 [官方配置研究](docs/OFFICIAL-CONFIG-RESEARCH.md)。

存档采用 schema 1，通过共享平台适配层存储。每次变更先写入再替换内存数据；保存失败不扣款。对局使用流水号和累计奖励账本，重复结算不会重复发币。跨日任务重置保留历史成就，日期回拨不能再次领取签到或免费补给。

## 开发与验证

在仓库根目录执行：

```bash
pnpm install --offline
pnpm --filter zombie-fire build
pnpm --filter zombie-fire test
pnpm --filter zombie-fire exec tsx tools/check-campaign.ts
pnpm --filter zombie-fire build:mini
pnpm --filter zombie-fire verify:mini
node scripts/verify-cocos-game.mjs zombie-fire web
node scripts/verify-cocos-game.mjs zombie-fire native
```

构建使用仓库锁定的官方 Creator 工具链，安装步骤见 [COCOS.md](../../docs/COCOS.md)。首次先执行官方构建，生成 `temp/declarations` 后再执行类型检查。不提供自制渲染器替代官方导出。浏览器验证支持 `VERIFY_VIEWPORT=320/390/844/1440` 单独复现；Linux 浏览器共享依赖设置沿用根目录验证说明。

测试驱动仅在 `__COLLECTION_TEST__` 显式启用时暴露，只推进固定步长并选择当前真实卡牌，不修改生命、货币、敌人或胜负。端到端流程以新存档开始，通过战斗获得购买用的金币，并实际点击升级、换装、镶嵌、领取和重载。

## 资源

场景、敌人、角色、时装和技能图标由 `art.ts`、`infected.ts`、`illustration.ts`、`icons.ts` 原创绘制。`tools/make-assets.py` 用 Python 标准库生成原创合成音频和稳定 Creator 元数据。资源清单见 [ASSETS.md](docs/ASSETS.md)。参考官网的图片只在忽略目录用于比较，不进入发行包。

发布必须由仓库根脚本聚合全站；此游戏不能独立覆盖 `gh-pages`。完整验收前不加入已发布的大厅目录。
