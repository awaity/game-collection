# 参考与移植记录

- 原作：<https://final-door-eight.vercel.app/>，页面程序版本 **1.5.0**。
- 采集：2026-10-16。取得公开页面完整 HTML、内联脚本和移动端实机截图；在本地重新运行该页面，采集 390×844 和 1440×900 的初始、过门、补给、首领、结算、更多菜单状态。
- 规则：`core.ts` 从该版本独立仿真移植为有显式数据类型的 TypeScript，保持原来的 60 Hz 更新、144 人容量、2048 发弹丸容量、输入记录和校验算法。
- 参考基准：`tests/reference-golden.json` 来自原作程序的种子 42、三条路线、0/6/15/25/35/45 秒状态。测试比较完整状态的校验值，不仅比较 UI 数字。
- 美术：`atlas.png` 是原作生成的 64 格动作图集（轻装、重装、赤潮成员和倒地）；`silhouette.png` 是相同模型的投影；`models.bin` 是原作的桥灯、门、补给、武器、障碍和首领程序化网格；`boss-joints.bin` 保存首领逐顶点关节参数，使用原作的举臂、重击与倒地方程。
- 移植后的运行时仅使用 Cocos `MeshRenderer`、Cocos 材质与本地资源；原作 WebGL 渲染器不作为本游戏运行时依赖。网格位置保留 Float32，索引使用 Uint16，法线与颜色紧凑存储，解码后交给 Cocos。
- 音效使用本地生成的三种短音，对应原作命中、升级和重击的音高与包络；字体使用系统中文无衬线字体。
- Web 的可访问按钮与原生 Cocos 按钮共用动作与位置；原生回放导入/导出使用剪贴板，Web 使用 JSON 文件。
