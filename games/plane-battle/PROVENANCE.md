# 来源与迁移范围

来源：https://github.com/awaity/my-game-plane

上游版本：`f9a6cac32518c800c6a0035f90a79fdfefc954ce`（first commit）。`upstream/` 保留该提交的 Web 游戏、页面、样式和原始 README，用于审阅与来源追踪，不参加任何生产构建。原 README 声明 MIT；原仓库没有独立 LICENSE 文件，本项目不代替原作者补写许可。

迁移以 Web 游戏为基准：保留两种模式、三档难度、五级武器、护盾、生命补给、普通／精英敌机和 Boss 弹幕；将仿真、绘制、交互迁为共享 TypeScript，实现真正的微信／抖音小游戏入口。上游 `wechat-miniprogram` 是 WXML 小程序页面，页面没有接入其独立游戏引擎，因此不作为小游戏实现迁入。

修正：固定 60 Hz 消除帧率差异；每次新建对局重置计时器和 Boss 门槛；一枚子弹只命中一个存活目标、一个敌机只计分一次；四边清理弹幕；保留零坐标输入并处理取消触摸与后台暂停；击败 Boss 后暂停弹幕结算；旧 `highScore` 在同源可用时一次性迁入命名空间，保留旧键。无限模式原来递增难度的分支不可达，现每 30 秒提升一轮压力（保持没有 Boss 的无限玩法）。原域名的 localStorage 无法从新域名直接读取。

2026-10-19 按用户授权扩展：新增四大空域、十二个有限任务，气流、精英比例、补给周期和首领射击节奏随任务变化；无尽每两级轮换空域。加入独立金币、签到、任务、成就、五款战机配色和三项永久强化。强化影响实际子弹伤害、射击间隔与生命，装填保留小数时间，使一级强化即可增加发射次数。连续过关与直接选中同一任务采用一致的击破目标和生成间隔。

这些规则属于合集扩展，不描述为上游原有行为。`upstream/` 与原仓库保持不变；新增存档使用 `plane-battle.career.v1`，原高分和设置仍保留。内容及验证范围见 [扩展说明](../../docs/EXPANSION-2026-10.md) 与 [合集验证记录](../../docs/MULTIPLATFORM-VERIFICATION.md)。
