- 官方 App Store：[Temple Run](https://apps.apple.com/us/app/temple-run/id420009108)，官方公开 lookup 接口返回开发者 Imangi Studios, LLC、版本 1.42.0。
- 官方描述明确：自动逃离追兽、滑动转弯/跳跃/滑铲、古庙/桥梁/危险路径、收集金币、角色解锁和道具强化。
