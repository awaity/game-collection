# 山海逃亡

以《山海经》为故事背景的第三人称 3D 跑酷。带走照夜玉，惊醒守山兽，在昆仑、青丘、赤水和归墟的古道上寻回山海图。参考《神庙逃亡》的转弯、跳跃、滑铲与追逐机制，代码、美术和音频独立实现。

- 自动前进；普通路段左右变道，临近直角路口时按提示左右转弯，错过或转错会坠落。
- 盘根、低梁、断桥、落石、火障、移动石刃。碰撞后追兽逼近，连续失误会被捕。
- 八项递进试炼、无尽、每日固定种子挑战、逐步等待正确操作的身法教学。
- 灵玉、签到、每日任务、成就、五套独立造型、四项五级法宝修习、区域图鉴和本机纪录。
- 引玉铃吸附灵玉，玄龟符抵挡一次碰撞（不防坠落），乘风翎穿障并自动转弯。拾玉蓄满后可主动御风。

行装页支持五套衣装实时试穿，预览不扣灵玉、不改变装备。角色增加面部、发束、交领、护肩、玉佩、鞋靴和连续飘带；青丘狐裳、羽民流光、毕方赤羽、望舒月影各有独立尾/翼/月轮轮廓与法术光效。拾玉、跳跃、滑铲、转弯、受击与御风增加短时反馈；低画质降低粒子，减少动态关闭装饰运动。

触屏：上滑跳跃、下滑滑铲、左右滑动变道或转弯。桌面：方向键/WASD、空格跳跃、F 御风、P/Esc 暂停、R 重开。设置中可关闭辅助按键、音效、音乐与动态，并切换画质。后台切换会暂停，返回后手动继续。

无尽拾玉双倍、每次进入新区额外 100 灵玉；试炼通关奖励 100，首通再奖 150。签到 100–250，任务与成就可手动领取。一次对局最多花费 150 灵玉还魂一次，每日挑战与教学不提供还魂。装扮只有外观差异，法宝升级下次出发时生效；每日挑战统一初始法宝。灵玉与解锁保存在本机，不跨设备同步。

技术栈为官方 Cocos Creator 3.8.8 + TypeScript。核心规则、Session 与存档无引擎/DOM依赖；平台服务复用合集适配层。Web、微信、抖音运行同一场景和规则。生产构建只有显式 `__COLLECTION_TEST__` 时开放 QA 入口，验证只用合法动作推进。

在仓库根目录使用 pnpm：

```bash
pnpm --filter shanhai-run test
pnpm --filter shanhai-run build
pnpm --filter shanhai-run build:mini
pnpm --filter shanhai-run verify:mini
node scripts/verify-cocos-game.mjs shanhai-run all
```

Web 输出 `dist/web`，原生输出 `dist/weixin` 和 `dist/douyin`。官方工具、真机与平台审核状态见 [验收记录](docs/VERIFICATION.md)。由根目录统一发布完整站点。

美术使用原创合并几何、顶点色与山雾 shader；音频由 `python3 games/shanhai-run/tools/make-audio.py` 确定性生成。第三方游戏素材没有放入产品，参考采集与边界见 [REFERENCE.md](docs/REFERENCE.md)。
