# 参考与移植记录

参考：<https://endless-night.qilei991012.chatgpt.site>，2026-10-16 采集。原页面、应用模块、四角色、六关卡环境及几何/纹理保存在本地 `artifacts/public-references/endless-night/`、`artifacts/endless-assets/`。公开采集归档来自临时 Actions 运行 38906476361、38908428721。

## 规则

`domain.ts` 保留来源固定 60Hz 仿真、原版 Rapier 0.21.0 物理、所有敌人 AI 注册、武器/进化、被动/遗物、升级选卡/重抽/放逐/跳过、消耗品、五烽火和守夜人连战。所有战斗伤害、碰撞、击杀、升级、余烬、死亡及胜利均由同一套仿真计算。

`tests/reference-golden.json` 是在未修改玩法的原站模块实际运行得到的 36 个完整状态哈希（六场景各六个 600 帧检查点），覆盖四角色、血月与连战；使用相同初始条件、移动、技能、消耗品与选卡。仅忽略引擎对象引用，并对数值保留六位小数。期望值不能由移植版本重新生成。

`session.ts` 负责菜单/战斗/暂停/结算转换、合法存档恢复、每次消费扣减及每局奖励一次结算。与来源相同，只持久化永久进度和设置，不保存正在进行的战局。

## 画面与声音

程序模型、UV、法线、顶点色、材质和层级来自源站实际对象；几何有界量化并 gzip 压缩，纹理保持 PNG。分为公共素材、六关卡及音频，按需加载；没有将截图作为游戏背景或伪造场景。

人物、怪物和战斗特效移植原版动画；烽火点亮、环境火焰、水车、风中植被、萤火/余烬/飘雪和迷雾使用原版参数。Creator 材质实现卡通月光、提灯光照、雾与发光；抗锯齿、阴影/泛光和原站 Three 后处理存在实现差异，不宣称逐像素一致。

原版 WebAudio 音效、菜单/各环境/胜利配乐通过 OfflineAudioContext 离线合成，编码为本地 MP3，由 Creator AudioSource 播放。战斗音乐按低、中、首领三档强度切换。原版每次实时随机生成旋律，移植版为已烘焙的循环片段；所有音量、暂停、后台停音仍由游戏设置和生命周期控制。

## 原生构建

微信/抖音运行官方 Creator 原生导出；资源使用平台分包。Rapier WASM 解压后置于静态 `subpackages/night-physics/rapier.wasm`，先加载分包再调用 WXWebAssembly/TTWebAssembly；不向用户目录写 WASM，也不依赖浏览器 WebAssembly 回退。细节与验证边界见根目录 `docs/COCOS.md` 和本游戏验证记录。
