# 视觉与交互

原始需求：单人持枪左右滑动，左边射击武器门，右边阻挡僵尸，危机后通过武器升级清场。先完成浏览器版，同一套游戏随后接微信和抖音小游戏。

以「封锁中的城市高架」为场景。2.5D 透视跑道、玩具质感人物、黄黑隔离线是主视觉。避免把游戏包装成网页仪表盘，手机屏幕全部留给可操作战场。

色板：雾绿 #e4ebe1（网页与雾气）、松绿 #183f3d（文字）、混凝土 #b8c5b5（跑道）、装备蓝 #258eaf（升级门）、警示黄 #f5c451（玩家与主按钮）、尸潮红 #df6b60（敌区与危险）。僵尸使用灰绿色皮肤和紫褐破衣，减少写实恐怖。

字体：中文使用系统苹方/微软雅黑粗体；数字与英文使用 Arial Black / Arial，无远程字体。大标题、门上效果、剩余耐久优先；操作仅提示“左边升级 / 右边开火”。

布局：桌面左侧标题与玩法、中央独立竖屏战场、右侧武器说明；手机只保留战场。战场上方状态，中部前后景与门，下方角色/移动区/空袭。开始和结算在同一画布显示。

```
桌面： [ 标题 / 操作 ] [ 血量 · 波次 · 暂停 ] [ 武器成长 ]
                       [ 武器门 | 尸潮    ]
                       [     拖动角色    ]
                       [ 当前武器 | 空袭 ]
手机：                 [ 同一完整画布     ]
```

复核：主角是可玩的封锁线，非通用宣传页。顶部只显示必要信息。胜负真实计算，不用定时假胜利。游戏图形和 UI 全部 Canvas 绘制，Web 外壳不承担游戏交互。
