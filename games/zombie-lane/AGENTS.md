# 尸潮防线

- 本项目是 `games/zombie-lane/` 中的独立小游戏，与旁边的 `../volley-run` 保持源码隔离；此次工作区迁移已获用户授权。
- 统一使用 pnpm 与根目录锁文件；从根目录通过 `pnpm --filter zombie-lane <命令>` 运行。本游戏不独立发布 gh-pages，由根目录发布大厅和所有游戏。
- 用户要求技术栈兼顾微信小游戏和抖音小游戏：游戏逻辑、Canvas 渲染和游戏 UI 必须复用。浏览器 DOM、wx、tt 只能出现在对应平台入口/适配层。
- `src/core/` 不得依赖浏览器、Canvas 或平台全局；固定步长与确定性随机数便于验证。
- `src/render/` 与 `src/app.ts` 不依赖 DOM；平台能力经 `Platform` 注入。
- 实装浏览器功能后运行 typecheck、单元测试、三端打包，启动本地预览并检查桌面与手机尺寸。
- 小游戏打包成功不等于微信/抖音真机验证通过；如实记录验证范围。
